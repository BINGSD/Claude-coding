# Apex Maths — A Level Maths Tutoring Website

A static tutoring course website for A Level Mathematics students, built with plain HTML, CSS and JavaScript (no frameworks, no build step).

## Pages
- `index.html` — home page: hero, courses overview, why us, how it works, pricing, tutors, testimonials, FAQ and trial-booking form
- `courses.html` — full syllabus for Pure, Statistics, Mechanics and Further Maths, with worked examples and a weekly class timetable
- `styles.css` — all styling, including a CSS-only mobile menu and responsive layouts
- `script.js` — interactive features: practice quiz with instant marking, booking-form validation and confirmation, animated stats, scroll highlighting, syllabus search, per-course progress tracking (saved in the browser), today's classes in the timetable, and a back-to-top button

The pages still work if JavaScript is turned off; the scripts only add features.

## Run it
Open `index.html` in any browser.

The booking form validates input and shows a confirmation, but does not send submissions anywhere; connect it to a form service (e.g. Formspree, Netlify Forms) to receive submissions.
