# Apex Maths — A Level Maths Tutoring Website

A static tutoring course website for A Level Mathematics students, built with plain HTML and CSS (no JavaScript, no build step).

## Pages
- `index.html` — home page: hero, courses overview, why us, how it works, pricing, tutors, testimonials, FAQ and trial-booking form
- `courses.html` — full syllabus for Pure, Statistics, Mechanics and Further Maths, with worked examples and a weekly class timetable
- `styles.css` — all styling, including a CSS-only mobile menu and responsive layouts

## Run it
Open `index.html` in any browser.

The booking form is for display only; connect it to a form service (e.g. Formspree, Netlify Forms) to receive submissions.
