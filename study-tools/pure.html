1Proof

Year 1 + 2
Key points
  • Deduction: start from known facts and use logical steps to reach the statement.
  • Exhaustion: split into a finite number of cases (e.g. n odd / n even) and prove every case.
  • Counter-example: one example where the statement fails is enough to disprove it.
  • Contradiction: assume the statement is false and show this leads to something impossible (e.g. √2 is irrational, there are infinitely many primes).
  • Use 2n for any even number and 2n + 1 for any odd number, where n is an integer.
ExampleProve that the sum of any three consecutive integers is a multiple of 3.
Show solutionHide solution
  1. Let the integers be n, n + 1, n + 2, where n is an integer.
  2. Sum: n + (n + 1) + (n + 2) = 3n + 3 = 3(n + 1).
  3. n + 1 is an integer, so the sum is 3 × an integer.
The sum is a multiple of 3, as required.
Exercise
  1. [2]Disprove: “n² + n + 41 is prime for every positive integer n.”
    Show answer

    Counter-example: n = 40 gives 1681 = 41², which is not prime.

    Any single value that fails is enough. n = 41 also works: 41(41 + 1 + 1) = 41 × 43.

  2. [3]Prove that n² − n is even for every integer n.
    Show answer

    n² − n = n(n − 1), a product of two consecutive integers.

    One of any two consecutive integers is even, so the product is even. (Or by exhaustion: try n = 2k and n = 2k + 1.)

Common mistake

Checking a few examples is not a proof. Always finish with a concluding sentence that repeats what you were asked to prove.

2Algebra & quadratics

Year 1
Key points
  • Laws of indices: am × an = am+n, (am)n = amn, a−n = 1/an, a1/n = ⁿ√a.
  • Rationalise a denominator a + √b by multiplying top and bottom by a − √b.
  • Completing the square turns x² + bx + c into (x + b/2)² − (b/2)² + c. This gives the turning point.
  • For quadratic inequalities, find the roots, sketch the curve, then read off the region.
  • The factor theorem: if f(a) = 0 then (x − a) is a factor of f(x).
Formulas
  • Quadratic formula x=−b±b2−4ac2a
  • Discriminant b² − 4ac > 0 two real roots, = 0 one repeated root, < 0 no real roots
  • Difference of two squaresa² − b² = (a + b)(a − b)
ExampleFind the values of k for which x² + kx + 9 = 0 has no real roots.
Show solutionHide solution
  1. No real roots means b² − 4ac < 0.
  2. Here a = 1, b = k, c = 9, so k² − 36 < 0.
  3. Critical values k = ±6. The graph of k² − 36 is a ∪ shape, negative between the roots.
−6 < k < 6
Exercise
  1. [3]Rationalise 63−3, giving your answer in its simplest form.
    Show answer

    3 + √3

    Multiply by (3 + √3)/(3 + √3): 6(3 + √3)/(9 − 3) = 6(3 + √3)/6.

  2. [3]Write x² − 8x + 3 in the form (x + p)² + q and state the minimum point of the curve.
    Show answer

    (x − 4)² − 13, minimum point (4, −13)

    Halve −8 to get −4, then subtract (−4)² = 16: 3 − 16 = −13.

Common mistake

Multiplying or dividing an inequality by a negative number reverses the sign. And never divide both sides by x: you might lose a solution or divide by zero.

3Functions & graphs

Year 1 + 2
Key points
  • A function maps each input to exactly one output. The set of inputs is the domain; the outputs form the range.
  • fg(x) = f(g(x)): apply g first, then f.
  • f−1 exists only if f is one-to-one. Its graph is the reflection of y = f(x) in y = x. The domain of f−1 is the range of f.
  • |f(x)| reflects the parts below the x-axis upwards; f(|x|) reflects the right-hand half in the y-axis.

Examplef(x) = 2x + 1 and g(x) = x². Find fg(3), gf(3) and f−1(x).
Show solutionHide solution
  1. fg(3) = f(g(3)) = f(9) = 2(9) + 1 = 19.
  2. gf(3) = g(f(3)) = g(7) = 49. Note fg ≠ gf.
  3. For the inverse, write y = 2x + 1 and rearrange: x = (y − 1)/2.
fg(3) = 19, gf(3) = 49, f⁻¹(x) = (x − 1)/2
Exercise
  1. [3]y = f(x) has a maximum at (2, 5). Find the maximum of (a) y = f(x − 3) (b) y = 3f(x) (c) y = f(2x).
    Show answer

    (a) (5, 5)   (b) (2, 15)   (c) (1, 5)

    f(x − 3) moves right 3; 3f(x) multiplies y by 3; f(2x) halves x.

  2. [2]Solve |2x − 3| = 5.
    Show answer

    x = 4 or x = −1

    Solve 2x − 3 = 5 and 2x − 3 = −5.

Common mistake

Changes inside the bracket do the opposite of what you expect: f(x + 2) moves the graph 2 to the left, and f(2x) halves the x-coordinates.

4Coordinate geometry

Year 1 + 2
Key points
  • Parallel lines have equal gradients. Perpendicular gradients multiply to −1.
  • A tangent to a circle is perpendicular to the radius at that point.
  • The perpendicular bisector of a chord passes through the centre of the circle.
  • An angle in a semicircle is a right angle.
  • Parametric equations give x and y in terms of a parameter t. Eliminate t to find the Cartesian equation.
Formulas
  • Gradientm=y2−y1x2−x1
  • Straight liney − y1 = m(x − x1)
  • Perpendicularm1 × m2 = −1
  • Distanced=(x2−x1)2+(y2−y1)2
  • Circle, centre (a, b)(x − a)² + (y − b)² = r²
ExampleFind the centre and radius of the circle x² + y² − 6x + 4y − 12 = 0.
Show solutionHide solution
  1. Complete the square in x: x² − 6x = (x − 3)² − 9.
  2. Complete the square in y: y² + 4y = (y + 2)² − 4.
  3. So (x − 3)² + (y + 2)² − 9 − 4 − 12 = 0, giving (x − 3)² + (y + 2)² = 25.
Centre (3, −2), radius 5
Exercise
  1. [3]Find the equation of the line through (2, −1) that is perpendicular to y = 4x + 3. Give it in the form ax + by + c = 0.
    Show answer

    x + 4y + 2 = 0

    Gradient −¼, so y + 1 = −¼(x − 2). Multiply by 4: 4y + 4 = −x + 2.

  2. [4]Find the equation of the tangent to (x − 1)² + (y − 2)² = 10 at the point (4, 3).
    Show answer

    y = −3x + 15

    Radius gradient from (1, 2) to (4, 3) is 1/3, so the tangent gradient is −3. Then y − 3 = −3(x − 4).

Common mistake

Signs flip in the circle equation: (x + 2)² means the centre has x-coordinate −2. Also, the equation gives r², so take the square root.

5Sequences & series

Year 1 + 2
Key points
  • Arithmetic: add the common difference d each time. Geometric: multiply by the common ratio r.
  • A geometric series converges (has a sum to infinity) only when |r| < 1.
  • Sigma notation: Σr=1n means add the terms for r = 1, 2, …, n.
  • The binomial expansion of (1 + x)n for negative or fractional n is infinite and valid only for |x| < 1.
Formulas
  • Arithmetic nth termun = a + (n − 1)d
  • Arithmetic sumSn=n2(2a+(n−1)d)
  • Geometric nth termun = arn−1
  • Geometric sumSn=a(1−rn)1−r
  • Sum to infinityS∞=a1−r,|r|<1
  • Binomial (any n)(1+x)n=1+nx+n(n−1)2!x2+⋯
ExampleA geometric series has second term 12 and fifth term 1.5. Find the sum to infinity.
Show solutionHide solution
  1. ar = 12 and ar4 = 1.5.
  2. Divide: r³ = 1.5 ÷ 12 = 0.125, so r = 0.5.
  3. Then a = 12 ÷ 0.5 = 24. Since |r| < 1 the sum to infinity exists.
  4. S∞ = 24 ÷ (1 − 0.5).
S∞ = 48
Exercise
  1. [2]An arithmetic series has first term 5 and common difference 3. Find the sum of the first 20 terms.
    Show answer

    670

    S₂₀ = 20/2 × (2 × 5 + 19 × 3) = 10 × 67.

  2. [4]Expand (1 + 2x)−1 up to the term in x³ and state the values of x for which it is valid.
    Show answer

    1 − 2x + 4x² − 8x³, valid for |x| < ½

    Use n = −1 with 2x in place of x. Valid when |2x| < 1.

Common mistake

When you replace x with 2x in a binomial expansion, the whole term is cubed: (2x)³ = 8x³, not 2x³.

6Trigonometry

Year 1 + 2
Key points
  • π radians = 180°. Use radians for all calculus with trig functions.
  • sec x = 1/cos x, cosec x = 1/sin x, cot x = 1/tan x.
  • To solve trig equations, find the calculator value, then use the graph or CAST diagram to find every solution in the interval.
  • a sin x + b cos x can be written as R sin(x + α) with R = √(a² + b²) and tan α = b/a.
  • Small angles (in radians): sin θ ≈ θ, tan θ ≈ θ, cos θ ≈ 1 − θ²/2.
Formulas
  • Arc lengths = rθ
  • Sector areaA = ½r²θ
  • Pythagorean identitiessin²x + cos²x = 11 + tan²x = sec²x1 + cot²x = cosec²x
  • Double angle (sin)sin 2A = 2 sin A cos A
  • Double angle (cos)cos 2A = cos²A − sin²A = 2cos²A − 1 = 1 − 2sin²A
  • Compound anglesin(A ± B) = sin A cos B ± cos A sin B
ExampleSolve 2cos²x − sin x − 1 = 0 for 0° ≤ x < 360°.
Show solutionHide solution
  1. Replace cos²x with 1 − sin²x: 2 − 2sin²x − sin x − 1 = 0.
  2. Rearrange: 2sin²x + sin x − 1 = 0, which factorises to (2 sin x − 1)(sin x + 1) = 0.
  3. sin x = ½ gives x = 30° or 180° − 30° = 150°.
  4. sin x = −1 gives x = 270°.
x = 30°, 150°, 270°
Exercise
  1. [2]A sector has radius 6 cm and angle 0.8 radians. Find its arc length and area.
    Show answer

    Arc 4.8 cm, area 14.4 cm²

    s = 6 × 0.8; A = ½ × 36 × 0.8.

  2. [4]Write 3 sin x + 4 cos x in the form R sin(x + α), with 0 < α < 90°. State the maximum value.
    Show answer

    5 sin(x + 53.1°), maximum 5

    R cos α = 3 and R sin α = 4, so R = √(9 + 16) = 5 and tan α = 4/3.

Common mistake

Check your calculator is in the right mode (degrees or radians) before every trig question. A calculator gives only one solution; there are usually more in the interval.

7Exponentials & logarithms

Year 1
Key points
  • loga x = n means an = x. ln is loge, the inverse of ex.
  • The gradient of y = ekx is kekx: proportional to the value itself, which is why it models growth and decay.
  • For a model y = abx, plotting log y against x gives a straight line with gradient log b and intercept log a.
  • For y = axn, plot log y against log x: gradient n, intercept log a.
Formulas
  • Product lawlog xy = log x + log y
  • Quotient lawlog (x/y) = log x − log y
  • Power lawlog xk = k log x
  • Special valuesloga a = 1,  loga 1 = 0,  eln x = x
ExampleSolve 32x − 10(3x) + 9 = 0.
Show solutionHide solution
  1. Notice 32x = (3x)². Let y = 3x.
  2. y² − 10y + 9 = 0 factorises to (y − 1)(y − 9) = 0.
  3. 3x = 1 gives x = 0; 3x = 9 gives x = 2.
x = 0 or x = 2
Exercise
  1. [2]Solve 5x = 20, giving your answer to 3 decimal places.
    Show answer

    x = 1.861

    Take logs: x ln 5 = ln 20, so x = ln 20 ÷ ln 5.

  2. [3]A population is modelled by P = 200e0.03t, where t is in years. Find when the population first reaches 500.
    Show answer

    t = 30.5 years (3 s.f.)

    e^(0.03t) = 2.5, so 0.03t = ln 2.5 and t = 0.9163 ÷ 0.03 = 30.54.

Common mistake

log(a + b) = log a + log b is false. The product law only works for log(ab).

8Differentiation

Year 1 + 2
Key points
  • dy/dx is the gradient of the curve. At a stationary point, dy/dx = 0.
  • Second derivative test: d²y/dx² > 0 minimum, < 0 maximum. If it equals 0, check the gradient either side.
  • Tangent gradient = m; normal gradient = −1/m.
  • Implicit: differentiate y terms and multiply by dy/dx. Parametric: dy/dx = (dy/dt) ÷ (dx/dt).
  • A curve is convex where f″(x) > 0, concave where f″(x) < 0; a point of inflection is where it changes.
Formulas
  • Powersd/dx (xn) = nxn−1
  • Exponentials & logsekx → kekxln x → 1/x
  • Trig (radians)sin kx → k cos kxcos kx → −k sin kx
  • Chain ruledydx=dydu×dudx
  • Product rule(uv)′ = uv′ + vu′
  • Quotient rule(uv)′=vu′−uv′v2
ExampleFind and classify the stationary points of y = x³ − 3x² − 9x + 5.
Show solutionHide solution
  1. dy/dx = 3x² − 6x − 9 = 3(x − 3)(x + 1).
  2. Set equal to 0: x = 3 or x = −1.
  3. y(3) = 27 − 27 − 27 + 5 = −22 and y(−1) = −1 − 3 + 9 + 5 = 10.
  4. d²y/dx² = 6x − 6. At x = 3: 12 > 0, minimum. At x = −1: −12 < 0, maximum.
Maximum (−1, 10), minimum (3, −22)
Exercise
  1. [3]Differentiate y = x²e3x.
    Show answer

    dy/dx = xe^(3x)(2 + 3x)

    Product rule: 2x·e^(3x) + x²·3e^(3x), then factorise.

  2. [3]Find the gradient of the curve x² + y² = 25 at the point (3, 4).
    Show answer

    −3/4

    Implicitly: 2x + 2y(dy/dx) = 0, so dy/dx = −x/y = −3/4.

Common mistake

Don't forget the chain-rule factor: d/dx (sin 3x) = 3 cos 3x, not cos 3x.

9Integration

Year 1 + 2
Key points
  • Integration reverses differentiation. Always add + c to an indefinite integral.
  • A definite integral gives the signed area between the curve and the x-axis. Area below the axis comes out negative, so split the integral at the roots.
  • Choose a method: reverse chain rule (spot f′(x)/f(x) etc.), substitution, by parts (product of two different types), or partial fractions (rational functions).
  • For by parts, let u be the part that gets simpler when differentiated (usually the polynomial; but if there's a ln x, let u = ln x).
  • Separable differential equations: get all the y terms on one side with dy, then integrate both sides.
Formulas
  • Powers (n ≠ −1)∫xndx=xn+1n+1+c
  • Reciprocal∫1xdx=ln|x|+c
  • Exponential∫ekxdx=1kekx+c
  • Trig∫ cos kx dx = (1/k) sin kx + c∫ sin kx dx = −(1/k) cos kx + c
  • By parts∫udvdxdx=uv−∫vdudxdx
ExampleFind the area enclosed between the curve y = 4x − x² and the x-axis.
Show solutionHide solution
  1. Roots: x(4 − x) = 0, so x = 0 and x = 4. The curve is above the axis between them.
  2. ∫04(4x−x2)dx=[2x2−x33]04
  3. = (32 − 64/3) − 0 = 32/3.

Exercise
  1. [4]Find ∫ x cos x dx.
    Show answer

    x sin x + cos x + c

    By parts with u = x, dv/dx = cos x: x sin x − ∫ sin x dx.

  2. [5]Solve dy/dx = 2xy, given that y = 3 when x = 0.
    Show answer

    y = 3e^(x²)

    ∫ (1/y) dy = ∫ 2x dx gives ln|y| = x² + c, so y = Ae^(x²). Then y(0) = 3 gives A = 3.

Common mistake

If part of the region is below the x-axis, integrating straight across will cancel areas out. Find the roots first and add the separate areas as positive values.

10Numerical methods

Year 2
Key points
  • Change of sign: if f is continuous and f(a), f(b) have opposite signs, there is a root between a and b.
  • It can fail: a repeated root (no sign change), or an asymptote (sign change without a root).
  • Iteration: rearrange f(x) = 0 to x = g(x) and use xn+1 = g(xn). Draw staircase or cobweb diagrams to show convergence.
  • Newton–Raphson fails if f′(xn) is zero or close to zero (near a turning point).
  • The trapezium rule overestimates for a convex curve and underestimates for a concave curve.
Formulas
  • Newton–Raphsonxn+1=xn−f(xn)f′(xn)
  • Trapezium rule∫≈h2[y0+2(y1+⋯+yn−1)+yn],h=b−an
ExampleShow that f(x) = x³ − 2x − 5 has a root between 2 and 3, then use Newton–Raphson with x0 = 2 to find x2 to 4 d.p.
Show solutionHide solution
  1. f(2) = −1 < 0 and f(3) = 16 > 0. There is a change of sign and f is continuous, so there is a root in [2, 3].
  2. f′(x) = 3x² − 2, so f′(2) = 10 and x1 = 2 − (−1)/10 = 2.1.
  3. f(2.1) = 0.061, f′(2.1) = 11.23, so x2 = 2.1 − 0.061/11.23 = 2.094568…
x₂ = 2.0946 (4 d.p.)
Exercise
  1. [5]Use the trapezium rule with 4 strips to estimate ∫01ex2dx to 3 d.p. Is it an over- or underestimate?
    Show answer

    1.491, an overestimate

    h = 0.25; y-values 1, 1.06449, 1.28403, 1.75505, 2.71828. 0.125 × [1 + 2.71828 + 2(4.10357)] = 1.4907. The curve is convex, so the trapezia sit above it.

  2. [3]Use xn+1 = ∛(2xn + 5) with x0 = 2 to find x1, x2, x3 to 4 d.p.
    Show answer

    2.0801, 2.0924, 2.0942

    This is a rearrangement of x³ − 2x − 5 = 0, so it converges to the same root as the worked example.

Common mistake

For a sign-change argument you must state three things: both values with their signs, that there is a change of sign, and that f is continuous on the interval. Then conclude.

11Vectors

Year 1 + 2
Key points
  • A vector has magnitude and direction. Write it as ai + bj + ck or as a column.
  • The position vector of point A is a = OA. The vector from A to B is b − a.
  • Vectors are parallel if one is a scalar multiple of the other.
  • A unit vector has magnitude 1: divide the vector by its magnitude.
  • To show points are collinear, show two vectors between them are parallel and share a point.
Formulas
  • Magnitude|ai+bj+ck|=a2+b2+c2
  • Vector A to BAB = b − a
  • Unit vectora^=a|a|
ExampleA is (1, 2, −1) and B is (4, −2, 11). Find the distance AB and a unit vector in the direction of AB.
Show solutionHide solution
  1. AB = b − a = 3i − 4j + 12k.
  2. |AB| = √(9 + 16 + 144) = √169 = 13.
  3. Unit vector: divide each component by 13.
AB = 13; unit vector (3i − 4j + 12k)/13
Exercise
  1. [2]a = 2i − j and b = i + 3j. Find |a + b| in exact form.
    Show answer

    √13

    a + b = 3i + 2j, and √(9 + 4) = √13.

  2. [2]Show that p = 3i − 6j + 9k is parallel to q = −i + 2j − 3k.
    Show answer

    p = −3q, so p and q are parallel.

    Each component of p is −3 times the matching component of q.

Common mistake

AB = b − a (end minus start), not a − b. Getting this backwards reverses the direction.
