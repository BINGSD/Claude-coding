# A Level Maths Toolkit

A free study site for A Level Mathematics, built with HTML and CSS only (no JavaScript).

## Pages
- `index.html`: home page with a 5-minute warm-up quiz and links to every tool
- `pure.html`: 11 Pure topics
- `statistics.html`: 6 Statistics topics
- `mechanics.html`: 7 Mechanics topics
- `formulas.html`: what to learn vs what's given, exact trig values, derivatives and integrals, key graphs, normal critical values
- `exam.html`: command words, mark types, pacing, calculator skills, top 10 mistakes, revision checklist
- `study.css`: shared styles (light and dark mode)

Every topic has notes, key formulas, a worked example with a hidden step-by-step solution, two practice questions with hidden answers, and a common mistake to avoid. Solutions open with native `<details>` elements, so no scripts are needed.

## Use it
Open `index.html` in a browser.
